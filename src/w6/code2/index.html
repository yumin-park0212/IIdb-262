1. 미디어 쿼리가 필요 없는 반응형 (Grid auto-fit)

단순히 열(Column)의 개수만 줄어드는 카드 목록은 미디어 쿼리를 쓰지 않습니다. 최소 너비(160px)만 지정하면 스스로 공간을 계산해 줄바꿈합니다.

2. 요소의 노출/숨김 전환 (GNB 메뉴 ↔ 햄버거 버튼)

공간이 좁아졌을 때 기존 요소를 아예 숨기고(display: none) 새로운 모바일 전용 요소를 꺼내는 작업은 미디어 쿼리로만 가능합니다.

3. 컴포넌트 배치 축 전환 (flex-direction: row → column)

데스크탑에서는 이미지와 글이 좌우(가로)로 배치되다가, 모바일에서는 위아래(세로)로 쌓이도록 축을 꺾어줍니다.

반응형 웹 디자인 마스터 클래스

화면 크기에 따라 레이아웃의 축이 가로에서 세로로 전환되며, 모바일에서는 텍스트와 버튼이 중앙 정렬로 바뀝니다.

4. 전체 레이아웃 해체 및 폰트/여백 축소

데스크탑의 2단 그리드(사이드바+본문)를 모바일에서는 1단으로 해체하고, 좁은 화면에 맞춰 제목 크기와 박스 안쪽 여백(padding)을 줄입니다.

본문 영역의 안쪽 여백(padding)도 모바일에서는 더 좁게 조정되어 화면 공간 효율을 높입니다.
